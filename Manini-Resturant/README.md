# 🍕 Manini-Resturant
A Full-Stack Restaurant Management System built with Laravel, MySQL, and Vite.

## 🚀 Installation Guide
If you are cloning this project, follow these steps to get it running locally:

1 **Clone the repository**
2 **Install Dependencies**
   composer install
   npm install

3 Environment Setup

    Copy .env.example to .env

    Run php artisan key:generate

4 Database Configuration

    Create a database named ManiniDB in XAMPP/phpMyAdmin.

    Update your .env file with your database credentials.

    Run php artisan migrate

5 Start the App

    php artisan serve
    npm run dev
